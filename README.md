# DinoQuest — Долина героев

Мобильная RPG с автоматическими боями, прокачкой героя, спутником, сундуками, заданиями и сохранением. Сделана на Godot 4.4.1. Графика рисуется средствами Godot, внешние картинки не нужны.

## Скачать Android APK

Открой [сборки Android](../../actions/workflows/build-android-apk.yml). Выбери **последний успешный** запуск, открой его и скачай артефакт `DinoQuest-Android-APK`. В архиве будет `DinoQuest.apk` для установки на Android.

Важно: APK появляется только **после успешного завершения** GitHub Actions; наличие workflow не гарантирует успешную сборку.

## Запуск на ПК

Скачай исходники репозитория (Code → Download ZIP), открой `project.godot` в Godot 4.4.1+ и нажми F5.

## Файлы

- `main.gd` — игровой цикл, UI, улучшения, квесты, сохранение;
- `battle.gd` — оригинальная процедурная графика;
- `main.tscn` — главная сцена;
- `export_presets.cfg` — экспорт Android;
- `.github/workflows/build-android-apk.yml` — автоматическая сборка debug APK.

Это оригинальный небольшой idle-RPG прототип и не копия персонажей или графики Hero Dino.
