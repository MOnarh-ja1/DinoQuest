# DinoQuest: Долина героев

Мобильная idle-RPG на Godot 4.4, оригинальные персонажи, автономное прохождение, прокачка и сохранения.

## APK

Сборка Android запускается автоматически при изменениях в `main` через GitHub Actions. Скачать установочный файл можно в разделе [Actions](../../actions/workflows/build-android-apk.yml) → последний успешный запуск → `DinoQuest-Android-APK`.

Исходники Godot упакованы в `DinoQuest_Godot_Source.zip`. Workflow распаковывает их перед экспортом.
